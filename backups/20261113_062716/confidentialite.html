Politique de Confidentialité

En résumé : Nous collectons le minimum nécessaire pour faire fonctionner KWATTA. Nous ne vendons jamais vos données.

1. Données collectées

  • Compte : email, nom d'utilisateur, nom complet, numéro WhatsApp, ville
  • Activité : annonces publiées, messages envoyés, favoris
  • Technique : type d'appareil, adresse IP (anonymisée après 30 jours)

2. Utilisation

  • Fournir le service (afficher les annonces, la messagerie)
  • Sécuriser votre compte (détection de fraude)
  • Améliorer KWATTA (statistiques anonymisées)
  • Respecter nos obligations légales

3. Partage

Nous ne vendons JAMAIS vos données. Elles peuvent être partagées avec :

  • Supabase (hébergeur de base de données, chiffré)
  • Autorités légales (uniquement sur réquisition)

4. Sécurité

  • Chiffrement HTTPS
  • Mots de passe hachés (irréversibles)
  • Base de données isolée par utilisateur (RLS)
  • Sauvegardes quotidiennes

5. Vos droits

  • Accès : voir toutes vos données
  • Rectification : modifier vos infos
  • Suppression : supprimer votre compte
  • Portabilité : exporter vos données

6. Cookies

Seulement pour la session (obligatoire). Aucun cookie publicitaire.

7. Conservation

  • Compte actif : tant que vous utilisez KWATTA
  • Compte supprimé : effacé sous 30 jours
  • Logs techniques : 6 mois maximum

8. Contact

Email : privacy@kwatta.cm
